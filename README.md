# Practical-Stand-AI-in-game-industry-for-AI-Course# Учебный стенд ИИ в игровой индустрии (Pygame Simulation)

Интерактивный программный комплекс, предназначенный для наглядной демонстрации школьникам и студентам классических подходов программирования искусственного интеллекта в видеоиграх.

## 🚀 Как запустить проект

1. Убедитесь, что у вас установлен Python версии **3.10 или выше**.
2. Установите зависимость Pygame через терминал/командную строку:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите симуляцию:
   ```bash
   python main.py
   ```

---

## 🎮 Управление в симуляции

* **Движение игрока (синий кружок):** Клавиши `W`, `A`, `S`, `D` или стрелки на клавиатуре.
* **Переключение режимов ИИ:** 
  * Нажатие мышкой по кнопкам **FSM**, **Flocking**, **Markov** на верхней панели.
  * Клавиши `1` (FSM), `2` (Flocking), `3` (Markov) для мгновенного переключения.
* **Выход из приложения:** Клавиша `ESC` или крестик окна.

*При каждом переключении или повторном нажатии на режим вся сцена полностью перезапускается в исходное состояние.*

---

## 🔬 Что демонстрирует каждый режим

### 1. FSM (Finite State Machine / Конечный автомат)
В этом режиме красный треугольник (NPC) управляется строгим набором правил на основе условий. У него есть 4 состояния:
* **Патруль:** Движется по круговой траектории.
* **Погоня:** Начинает преследовать игрока, если тот подошел ближе 300 px.
* **Атака:** Замирает на месте и мигает, когда дистанция до игрока становится меньше 80 px. В этот момент здоровье NPC планомерно снижается.
* **Отступление:** Если здоровье падает ниже 30 единиц, NPC панически убегает от игрока, пока не отойдет на безопасные 400 px, где восстанавливает силы и возвращается к патрулированию.

### 2. Flocking (Алгоритм стаи Крейга Рейнольдса)
Демонстрирует эмерджентное поведение группы из 30 независимых агентов без единого центра управления. Движение формируется балансом трех сил:
* **Separation (Разделение):** Избегание столкновений (расталкивание boids, если они ближе 40 px).
* **Alignment (Выравнивание):** Попытка двигаться с той же скоростью и вектором направления, что и соседи.
* **Cohesion (Сплочение):** Стремление лететь к среднему геометрическому центру масс окружающих агентов.

### 3. Markov Chain (Цепи Маркова)
Показывает вероятностную модель принятия решений, делая поведение противников непредсказуемым. Решения принимаются раз в 2 секунды на основе матрицы переходных вероятностей. 
* Вы можете наблюдать, как бот переходит от пассивного **Укрытия** к фазам **Стрельбы** (луч на игрока) и броскам **Гранаты** (круговые зоны вокруг игрока). Стенд собирает статистику срабатываний для верификации теории вероятностей.

## 🛠️ Что можно изменить для экспериментов (Конфигурирование)

Все ключевые параметры симуляции вынесены в файл `config.py`. Вы можете открыть его и изменить:
1. `FLOCK_WEIGHT_...` — измените веса сил стаи (например, обнулите выравнивание и посмотрите, как распадется упорядоченное облако).
2. `MARKOV_MATRIX` — измените коэффициенты вероятностей, чтобы заставить NPC чаще бросать гранаты или уходить в защиту.
3. `FSM_DIST_CHASE` и `FSM_DIST_ATTACK` — измените радиусы зрения и триггеры переключения автомата.
