# Practical-Stand-AI-in-game-industry-for-AI-Course# Учебный стенд ИИ в игровой индустрии (Pygame Simulation)

Интерактивный программный комплекс, предназначенный для наглядной демонстрации школьникам и студентам классических подходов программирования искусственного интеллекта в видеоиграх.

## 🚀 Как запустить проект

# По простому
1. Зайдите во вкладку Releases
2. First Release
3. Assets -> нажмите на файл main.exe и начнется установка
4. Запустите этот файл
5. В случае блокировки системой защиты windows нажмите на "Выполнить в любом случае"

# По айтишному
1. Убедитесь, что у вас установлен Python версии **3.10 или выше**.
2. Установите зависимость Pygame через терминал/командную строку:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите симуляцию:
   ```bash
   python main.py
   ```

## 🎮 Управление в симуляции

* **Движение игрока (синий кружок):** Клавиши `W`, `A`, `S`, `D` или стрелки на клавиатуре.
* **Переключение режимов ИИ:** 
  * Нажатие мышкой по кнопкам **FSM**, **Flocking**, **Markov** на верхней панели.
  * Клавиши `1` (FSM), `2` (Flocking), `3` (Markov) для мгновенного переключения.
* **Выход из приложения:** Клавиша `ESC` или крестик окна.

*При каждом переключении или повторном нажатии на режим вся сцена полностью перезапускается в исходное состояние.*

# 🎮 Учебный стенд игрового ИИ

Привет! Это лаборатория, где ты управляешь синим кружком (WASD или стрелки), а красные треугольники — компьютерные противники. Они ведут себя по-разному. Переключай режимы клавишами **1**, **2**, **3** или кнопками сверху. При смене режима всё начинается заново.

Твоя задача — за 3–5 минут **поиграть в каждом режиме** и заметить разницу. Вот что смотреть.

---

## 1. FSM — «ИИ с памятью и глазами» (клавиша 1)

**Что делает:** враг ходит по кругу, пока не увидит тебя. Увидел — бежит за тобой. Подбежал близко — атакует и отнимает здоровье. Если ты подходишь вплотную в момент атаки — он отступает.

**Что проверить:**
1. Встань далеко — враг патрулирует.
2. Выйди на открытое место — он сразу переключается в погоню.
3. **Главный тест:** забеги за серую стену. Враг **побежит к тому месту, где видел тебя в последний раз**, обогнёт стену и снова тебя найдёт. У него есть **память**.

**Вывод:** FSM действует по жёстким правилам «если — то», но **помнит**, где тебя видел.

---

## 2. Flocking — «стая без лидера» (клавиша 2)

**Что делает:** 30 треугольников летают стаей. У каждого всего три правила: не сталкиваться с соседом, лететь туда же, куда соседи, держаться ближе к толпе. Лидера нет — но стая ведёт себя как единое целое.

**Что проверить:**
1. Спрячься за стену — стая красиво кружится в левой части экрана, тебя не видит.
2. Выйди из-за стены — **вся стая разворачивается и летит на тебя**, пытаясь зажать в кольцо.
3. Обрати внимание: треугольники двигаются плавно и не ломаются, даже когда толкаются вокруг тебя.

**Вывод:** Flocking — это **эмерджентное поведение**: простые правила у каждого, сложное поведение у всех.

---

## 3. Markov — «робот-казино без памяти» (клавиша 3)

**Что делает:** враг каждые 2 секунды «бросает кубики» и выбирает действие: патрулировать, стрелять лазером или бросать гранату. Вероятности заданы в таблице. **Памяти у него нет.**

**Что проверить:**
1. Выйди на открытое место — враг случайно выбирает действия, ты теряешь здоровье.
2. **Главный тест (отличие от FSM):** забеги за стену. Враг **не пойдёт тебя искать** к углу стены. Он просто «ослеп» и кружится на месте. У него **нет памяти** о том, что ты только что был там.

**Вывод:** Markov — это **вероятностное поведение без памяти**. Он непредсказуем, но не помнит, где ты.

---

## Что ещё можно сделать

Открой `config.py` в текстовом редакторе и поменяй цифры:

- `FLOCK_COUNT = 30` → сделай стаю из 60 или 100 птиц.
- `MARKOV_MATRIX` → измени проценты, чтобы бот только бросал гранаты.
- `COLOR_WALL` → перекрась стены.

Смотри, как меняется поведение. Это и есть «крутить параметры ИИ».

---

## Главное, что нужно запомнить

| Режим | Память | Поведение |
|-------|--------|-----------|
| FSM | **Есть** | Жёсткие правила «если — то» |
| Flocking | Нет | Простые правила → сложная стая |
| Markov | **Нет** | Случайный выбор по вероятностям |
